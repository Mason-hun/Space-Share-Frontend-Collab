# SpaceShare – Frontend

SpaceShare is an on-demand workspace marketplace that helps people discover and book flexible workspaces.

## About the Project

The platform connects workspace seekers with available spaces such as desks, meeting rooms, private offices, training rooms, podcast studios, and creative spaces.

Users can search for workspaces by location, filter results, view workspace details, check availability, make bookings, and manage their booking history.

Hosts can list their available spaces, upload photos, set prices, manage availability, and manage bookings.

## Key Features

* User authentication and registration
* Workspace search and filtering
* Workspace details and availability
* Booking and checkout
* Booking history
* Host dashboard
* Corporate dashboard
* Ratings and reviews
* Responsive web interface

## Technologies

* HTML
* CSS
* JavaScript
* Tailwind CSS

## Project Goal

SpaceShare aims to make finding and booking flexible workspaces easier while helping space owners monetize unused workspace capacity.
